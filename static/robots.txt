# This stance is a decision, not a default. Crawlers that harvest pages into
# training corpora are turned away. Crawlers that fetch a page because a reader
# asked a question about it — and cite it back — are welcome, because that is
# increasingly how someone arrives at a post at all. Search engines are
# unaffected by either rule.
#
# There is no umbrella switch for this: every vendor honours its own
# user-agent string and ships new ones without notice, so the lists below are
# hand-maintained and will always be a little behind. Nothing here is
# enforcement; robots.txt is a request that well-behaved crawlers honour.
